## Deskripsi Proyek

Proyek ini mengimplementasikan dua model data mining:

### A. Klasifikasi Diabetes
Membangun model klasifikasi untuk memprediksi risiko diabetes berdasarkan data pasien menggunakan 3 algoritma:
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree

**Metrik Evaluasi:**
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

### B. Clustering Gerai Kopi
Analisis klaster untuk menganalisis persebaran gerai kopi dan mengidentifikasi zona berisiko sepi menggunakan:
- K-Means Clustering

**Fitur yang digunakan:**
- Koordinat geografis (Latitude & Longitude)
- Kepadatan pelanggan
- Tingkat kompetisi
- Jarak ke pusat kota
