## Penjelasan Proyek
Proyek ini merupakan aplikasi web interaktif yang dibangun menggunakan **Streamlit** untuk mengimplementasikan dua pemodelan *Data Mining*:

### A. Klasifikasi Diabetes (Supervised Learning)
Membangun model klasifikasi untuk memprediksi risiko diabetes berdasarkan data kesehatan pasien. Model ini membandingkan 3 algoritma:
- K-Nearest Neighbors (KNN)
- Naïve Bayes
- Decision Tree

**Luaran Metrik Evaluasi:** Accuracy, Precision, Recall, F1-Score, dan visualisasi Confusion Matrix.

### B. Clustering Gerai Kopi (Unsupervised Learning)
Analisis klaster untuk memetakan persebaran gerai kopi dan mengidentifikasi zona berisiko sepi berdasarkan kondisi geografis dan parameter lingkungan menggunakan algoritma:
- K-Means Clustering

**Fitur yang digunakan:** Koordinat geografis (Latitude & Longitude), Kepadatan pelanggan, Tingkat kompetisi, dan Jarak ke pusat kota.
